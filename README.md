# Prof. Dr. Ahmet Avcı – Kişisel Web Sitesi

Sade HTML, CSS ve JavaScript ile yazılmış tek sayfalık site. Derleme adımı yoktur.

- `index.html` – sayfa içeriği
- `style.css` – tasarım (lacivert / altın)
- `main.js` – menü, animasyonlar ve davet formu (ziyaretçinin e-posta uygulamasını açar)
- `img/` – görseller

## Yayın
Depo Vercel'e bağlandığında `main` dalına yapılan her değişiklik siteyi otomatik günceller.
Vercel ayarı: Framework Preset = "Other", Build Command boş, Output Directory = `.`
